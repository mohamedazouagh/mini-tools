# mini-tools

Small, tested command-line utilities for everyday data chores. Standard library only.

| Tool | What it does | Usage |
|---|---|---|
| `csvclean` | Trim cells, snake_case headers (clashing names get `_2`, `_3`; blank ones become `column_N`), drop empty/duplicate rows; `-d ';'` / `--out-delimiter` for non-comma files | `python -m minitools.csvclean in.csv out.csv --dedupe -d ';'` |
| `json2csv` | JSON array of objects (or JSON Lines via `--lines` / `.jsonl`) to CSV; nested keys flattened as `a.b`, missing keys and null left empty, booleans written as true/false; `--path data.items` unwraps an array inside an API response | `python -m minitools.json2csv in.json out.csv` |
| `csv2json` | CSV to a JSON array of objects (or `--lines` for JSON Lines); values stay strings unless `--types` (ints, decimals, true/false, empty → null; leading-zero IDs stay text); `--nest` rebuilds `a.b` headers into nested objects; blank/duplicate headers and over-long rows rejected; `-d`, `-o`, `--indent`, stdin via `-` | `python -m minitools.csv2json people.csv --types --nest -o people.json` |
| `datenorm` | Rewrite one CSV date column as ISO `YYYY-MM-DD`; ISO timestamps keep their date part (day-first by default, `--monthfirst` for US dates, `--strict` to fail on unparseable cells); `-d ';'` or `-d '\t'` for semicolon/tab files, output keeps the delimiter | `python -m minitools.datenorm in.csv out.csv -c date -d ';'` |
| `dedupe` | Drop duplicate lines while keeping the original order; `-i` ignore case, `-s` ignore surrounding spaces, `--skip-blank`, `--keep-last` to keep the final occurrence, `--only-dupes` to list only repeated lines (with counts under `--stats`), `--stats`, `--encoding cp1252` for legacy files (clear error on undecodable input) | `python -m minitools.dedupe emails.txt -o unique.txt -i -s --stats` |
| `wordfreq` | Line/word/char totals and the most frequent words across one or more files (case-insensitive, Unicode-aware); `--min-length`, `--min-count N` to hide rare words, `--stopwords FILE`, `--encoding cp1252` for non-UTF-8 files (clear error instead of a traceback), `--csv` | `python -m minitools.wordfreq notes.txt -n 10 --min-length 3` |
| `renamer` | Bulk-rename files in one folder with a regex (`\1` groups); dry run by default, `--apply` to rename; refuses the whole batch on name clashes; `--glob`, `-i` | `python -m minitools.renamer photos "^IMG_(\d+)" "trip_\1" --apply` |
| `csvstats` | Per-column profile of a CSV: filled/empty/distinct counts, plus min/max/mean for all-numeric columns (`nan`/`inf`/`1_000` count as text); `-d`, `--decimal-comma`, `--csv` | `python -m minitools.csvstats data.csv -d ";" --decimal-comma` |
| `csvsplit` | Split a CSV into files of N rows (`--rows`) or one file per column value (`--by`), header repeated in each; `--by` values differing only in case (`NL`/`nl`) share one file so no rows are lost on Windows/macOS; blank lines skipped, `-d`, `-o outdir`, refuses to overwrite unless `--force` | `python -m minitools.csvsplit sales.csv --by country -o parts` |
| `csvjoin` | Join two CSVs on a key column (inner or `--how left`), one-to-many matches kept, keys trimmed, `-i` matches keys regardless of case, clashing right columns get `_right`; `--right-key`, `-d`, `-o` refuses to overwrite unless `--force` | `python -m minitools.csvjoin orders.csv customers.csv -k customer_id -o joined.csv` |
| `csvcut` | Keep and reorder (`-c email,id`) or drop (`-x notes`) CSV columns by name; unknown names fail with the list of real headers, short rows padded, quoting preserved; `-r old=new` (repeatable) renames output columns; `--encoding cp1252` reads legacy exports and writes UTF-8 (clear error on undecodable input); `-d`, `-o`, stdin via `-` | `python -m minitools.csvcut contacts.csv -c email,name -r email=Email -o emails.csv` |
| `csvsort` | Sort CSV rows by one or more columns (`-k country,amount`); all-numeric columns sort as numbers, text case-insensitively, empty cells last even with `-r`; stable, unknown names list the real headers; quoted multi-line cells keep their line breaks; `-d`, `-o`, stdin via `-` | `python -m minitools.csvsort sales.csv -k country,amount -r -o sorted.csv` |
| `csvfilter` | Keep rows matching conditions like `amount>=100`, `country=NL`, `email~regex` (`=` `!=` `>` `>=` `<` `<=` `~` `!~`); repeat `-w` for AND or add `--any` for OR; numbers compare as numbers, text cells never match `>`/`<`; `-i`, `--count`, `-d`, `-o`, stdin via `-` | `python -m minitools.csvfilter sales.csv -w "country=NL" -w "amount>=100" -o nl_big.csv` |
| `csvdiff` | Compare two versions of a CSV by a key column: added (`+`), removed (`-`) and changed (`~`) rows with the cells that changed; row order ignored, cells trimmed, columns in only one file reported; duplicate keys rejected; `--summary`, `-d`; exit 0 identical / 1 different / 2 bad input | `python -m minitools.csvdiff old.csv new.csv -k id` |
| `csvstack` | Append several CSVs into one with a single header; columns may be in any order (matched by name), `--union` allows different columns and leaves missing cells empty, `--source NAME` adds a column with each row's file name; over-long rows and duplicate headers rejected, refuses to write over an input; `-d`, `-o` | `python -m minitools.csvstack jan.csv feb.csv mar.csv --source file -o q1.csv` |
| `dupfiles` | Find files with identical content in a folder tree (size first, then SHA-256 in chunks); read-only, never deletes; reports groups and reclaimable space; locked/unreadable files are skipped and listed on stderr instead of aborting the scan; `--min-size 1M`, `--glob`, `--no-recursive`, `--include-empty`, `--csv`; exit 0 none / 1 duplicates / 2 bad input | `python -m minitools.dupfiles downloads --min-size 1M --glob "*.pdf"` |
| `csvlook` | Preview a CSV as an aligned text table (numeric columns right-aligned) or `--markdown` table with pipes escaped; `-n` rows (default 20, 0 = all, "showing N of M" on stderr), `--max-width` cuts long cells with `…`, wide CJK characters kept aligned; `-c country,amount` shows only those columns in that order (unknown names list the real headers); `-d`, stdin via `-` | `python -m minitools.csvlook sales.csv -n 10 --markdown` |
| `csvfreq` | Frequency table of one column or a combination (`-c country,status`), most common first with count and share; cells trimmed, empty cells shown as `(blank)` or skipped with `--no-blank`, `-i` merges case variants (most common spelling shown), `-n` top N, `--sort value` for natural order (numbers numerically, `(blank)` last), `--encoding cp1252` for legacy exports (clear error on undecodable input), `--csv`, `-d`, stdin via `-` | `python -m minitools.csvfreq orders.csv -c country -n 5` |
| `csvsample` | Random sample of CSV rows with the header: `-n N` (one-pass reservoir sampling, fine for files bigger than memory) or `--frac 0.1`; `--seed` for a repeatable sample, rows stay in file order unless `--shuffle`; blank lines skipped, `-d`, `-o` refuses to overwrite unless `--force`, stdin via `-` | `python -m minitools.csvsample big.csv -n 100 --seed 42 -o sample.csv` |
| `lineends` | Report each file's line-ending style (LF / CRLF / CR / mixed) with counts, UTF-8 BOM and final newline; folders scanned recursively with `--glob`, binary files skipped; `--to lf` / `--to crlf` and `--strip-bom` are a dry run until `--apply`; `--check lf` exits 1 on other styles for CI | `python -m minitools.lineends data --glob "*.csv" --to lf --apply` |
| `csvcheck` | Validate CSV columns before loading: `-r column:rule` (repeatable) with `required`, `int`, `number`, `date` (real ISO dates), `email`, `unique`; cells trimmed, empty cells only fail `required`; problems listed with the line each row starts on (multi-line quoted cells handled), `--max-errors N`, `-d`, stdin via `-`; exit 0 valid / 1 problems / 2 bad input | `python -m minitools.csvcheck orders.csv -r id:unique -r amount:number -r date:date` |
| `csvgroup` | GROUP BY for CSVs: `-g country` (or `-g country,status`) with repeatable `-a count`, `col:sum`, `col:mean`, `col:min`, `col:max`, `col:distinct`; exact decimal sums (0.10 + 0.20 = 0.30), empty cells skipped, blank keys shown as `(blank)`, non-numbers fail with their line number (exit 2); groups sorted by key (numbers numerically), `--precision`, `--csv`, `-d`, stdin via `-` | `python -m minitools.csvgroup sales.csv -g country -a count -a amount:sum -a amount:mean` |
| `csvfill` | Fill blank cells down from the last value above (`-c region,store` or `--all`), for spreadsheet reports that show a group label only on its first row; `--within region` restarts filling at each new region so values never leak into the next group; `--up` fills from the next value below instead (for reports that put the label on a group's last/subtotal row); `--value 0` writes a fixed value instead; space-only cells count as blank, leading blanks stay blank, unknown names list the real headers; `--stats`, `-d`, `-o`, stdin via `-` | `python -m minitools.csvfill report.csv -c region,store -o tidy.csv` |
| `csvuniq` | Keep one row per key instead of per identical row: `-k customer_id` (or `-k email,country`) keeps the first row of each key, `--keep last` the final one (at its own position, for newer re-exports); key cells trimmed, `-i` ignores case, `--dupes` lists only the rows whose key repeats (all copies); `--count copies` adds a column with how many rows shared each key; `--stats`, `-d`, `-o`, stdin via `-`; unknown names list the real headers (exit 2) | `python -m minitools.csvuniq customers.csv -k customer_id --keep last -o unique.csv` |
| `csvmelt` | Wide to long: `-i store` keeps the id column(s) on every row and turns each other column (or only `-v jan,feb`, or glob patterns like `-v "2026-*"` that skip info columns) into its own row with the old header in `variable` and the cell in `value` (rename with `--var-name` / `--value-name`); `--skip-blank` drops empty or space-only cells, short rows padded, unknown/duplicate headers and id/value overlaps rejected (exit 2); `-d`, `-o`, stdin via `-` | `python -m minitools.csvmelt sales_wide.csv -i store --var-name month --value-name sales -o long.csv` |
| `csvpivot` | Long to wide, the inverse of `csvmelt`: `-i store` makes one row per id, `-c month` turns that column's values into headers and `-v sales` fills the cells; rows and new columns keep first-seen order, missing combinations empty or `--fill 0`; a repeated id/column pair fails with its line number unless `--keep first` / `--keep last`; keys trimmed, blank or id-clashing new headers rejected (exit 2); `-d`, `-o`, stdin via `-` | `python -m minitools.csvpivot sales_long.csv -i store -c month -v sales -o wide.csv` |
| `csvmask` | Pseudonymise or mask sensitive columns before sharing a CSV: `-c email` (repeatable) replaces cells with a short HMAC-SHA256 token, so the same value always gets the same token and joins/counts still work; `-c phone:mask` keeps only the last `--keep` characters (default 4), `-c name:blank` empties the cell, `-c email:email` hashes only the part before the @ and keeps the (lowercased) domain so counts per domain still work; `--salt` or `$CSVMASK_SALT` for the secret (warns without one), `-i` lowercases before hashing, cells trimmed, empty cells stay empty; unknown columns/modes and repeated columns rejected (exit 2); `-d`, `-o`, stdin via `-` | `python -m minitools.csvmask customers.csv -c email -c phone:mask --salt "$SECRET" -o share.csv` |
| `csvreplace` | Regex find-and-replace inside chosen CSV columns only (`-c phone,name` or `--all`; the header row is never changed and quoting stays valid): `\1` / `\g<name>` groups in `-r`, `--literal` for plain text, `--whole` to replace only cells the pattern matches completely (lookup-style `NL` but not `NLD`), `-i`, `--count` per column on stderr; bad patterns, group references and unknown columns rejected (exit 2); `-d`, `-o`, stdin via `-` | `python -m minitools.csvreplace orders.csv -c country -p "^(nl\|holland)$" -r NL -i -o fixed.csv` |
| `csvnum` | Rewrite formatted number columns (`1.234,50`, `1,234.50`, `€ 1 234,50`, `1'234.5`, `(12.00)`, `12.00-`) as plain decimals (`1234.50`, `-12.00`) keeping the written decimals; `--decimal dot` / `comma`, or the default `auto` per cell, which refuses to guess ambiguous cells like `1,234`; thousands groups must be 3 digits, currency signs and EUR/USD/GBP/CHF dropped, empty cells kept; unreadable cells left as-is and listed with line numbers on stderr, `--strict` fails (exit 1, nothing written); unknown columns list the real headers (exit 2); `-d`, `-o`, stdin via `-` | `python -m minitools.csvnum bank.csv -c amount,balance --decimal comma -d ";" -o clean.csv` |
